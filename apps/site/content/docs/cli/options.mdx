## Global flags

| Flag | Description |
| --- | --- |
| `-v, --version` | Print the installed Atlas version and exit. |
| `-h, --help` | Show help for Atlas or any subcommand. |

## Common analysis options

Most analysis commands accept these two on top of their own flags.

| Flag | Default | Description |
| --- | --- | --- |
| `-r, --root <dir>` | cwd | Project root to analyze. May also be passed positionally, so `atlas serve ./apps/web` and `atlas serve --root ./apps/web` are equivalent. |
| `-o, --out-dir <dir>` | `.atlas` | Directory for analysis output and the cache, relative to the root. |

## Getting help in the terminal

Every subcommand documents itself. If you'd rather stay in the shell than in these pages, the CLI will
tell you the same thing.

```bash
atlas --help
atlas serve --help
```

Prefer a written reference? Head back to the [command pages](/docs/cli/serve), or set defaults once in
[a config file](/docs/configuration).
